# WASANII DINNER NIGHT 2026

A starter front-end for the black-and-gold awards platform.

## Publish with Cloudflare Pages
- Framework preset: None
- Build command: leave blank
- Build output directory: `/` (or `.` if the dashboard requires a relative directory)
- Root directory: `/`

## Current scope
This first version is a public landing page showing the six approved categories and their vote prices. It does **not** yet accept nominee submissions, store records, process payments, or count votes. Those require a secure database/backend and will be added before those features are advertised as available.
